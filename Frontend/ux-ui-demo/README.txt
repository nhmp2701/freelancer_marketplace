Liên Kết Việt - Interactive HTML Prototype
Mở index.html để bắt đầu.
Luồng chính:
Đăng ký/Đăng nhập -> Trang chủ -> Tìm việc -> Chi tiết -> Proposal -> Tin nhắn
Client: Trang chủ -> Đăng dự án -> Freelancer/Profile/Invite -> Tin nhắn
Ví: Ví -> Nạp tiền/Rút tiền/Xuất sao kê -> Quay lại Ví
Admin: Dashboard -> Users/Projects/Transactions/Disputes
